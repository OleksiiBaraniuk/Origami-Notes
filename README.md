# Origami Notes

Origami Notes is a notes app with broad functionality that stays clean and uncluttered.
The goal: something that doesn't look like an engineering tool, has modern Material Design,
and centralizes ideas in one place — folders, drawings, whiteboards, todos, all together.

## Features
### Planned

Folder structure and possibility to place and store in user order is not only feature that important, and not only there will be. 
Full list of note types that would be implemented 
- Regular that all Know
  - Text Notes
  - List
- Unregular
  - Task List
  - Whiteboard
  - Draw
  
Along side with inside text edit with adding Quotes,Image, Video and etc. that makes it toward expected notes expirience.
I didnt talk about privacy, but i do know how important is to most of us. Origami notes stay and will stay as FOSS, same as archive format that comes, and will respect your choice. Notes itself dont collect any data, all will be stored localy on your devices. OR on cloud that you will decide you trust. There will be cloud save and sync option in future, with obvious popular options like: Google Drive, OneDrive, Dropbox, and also options for your own cloud, nextcloud, or etc.
